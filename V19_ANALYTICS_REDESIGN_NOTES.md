# v19 Analytics Redesign

This version redesigns the Admin Analytics tab to make it smaller, easier, searchable, and more user-friendly.

## Added / Improved
- Analytics filters: date range, grade, exact section, chart style.
- Normal-size charts instead of very large charts.
- Bar / Pie / Doughnut switch.
- Click chart bars/slices to open a pop-up with the students behind that chart point.
- Quick top lists under each chart.
- Most Late Students table with search box.
- Readable Chart Summary with names and section details instead of unclear Student # labels.
- PowerPoint export remains available for each chart and for all charts.
- Export respects selected date range, grade, and section filters.

## Kept from previous versions
- System Owner role.
- Admin permissions structure.
- Student details pop-up.
- UAE time display.
- Brevo email.
- PostgreSQL/Supabase DATABASE_URL support.
- AI Report and chatbot.
